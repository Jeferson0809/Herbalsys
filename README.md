# 🍃 HerbalSys – Sistema de Gestión para Droguerías Naturistas

<div align="center">


**Juan Sebastián Puerto** • **Jeferson Acevedo** 

---

</div>

El manejo de inventarios, ventas y clientes en droguerías naturistas suele realizarse mediante procesos manuales o con herramientas poco eficientes. HerbalSys nace como una solución web moderna y accesible que permite centralizar y automatizar todos estos procesos.

> **Objetivo:** Crear una plataforma que gestione productos, lotes, inventario, ventas, proveedores y clientes desde cualquier dispositivo.

---

## 📂 Estructura del repositorio

- `backend/` — Lógica del servidor (Node.js + Express).
- `frontend/` — Interfaz gráfica (HTML, CSS, JS, Bootstrap).
- `docs/`
  - `Informe_Final/`
  - `Diagramas_UML/`
  - `MER/`
  - `Storyboard/`
  - `Presentacion/`
- `assets/` — Logos, imágenes y recursos.
- `README.md` — Documentación principal.

---

## 🧩 Funcionalidades principales

- ✔ Gestión de productos (CRUD)
- ✔ Control de lotes y fechas de vencimiento
- ✔ Alertas de bajo stock
- ✔ Registro de ventas + facturación
- ✔ Historial de clientes
- ✔ Proveedores y órdenes de compra
- ✔ Reportes automáticos
- ✔ Autenticación y roles
- ✔ Diseño responsivo

---

## 🏗️ Arquitectura

```
Frontend (HTML, CSS, JS, Bootstrap)
            ↓
Backend (Node.js + Express)
            ↓
Base de Datos (Supabase / PostgreSQL)
```

---

## 🚀 Tecnologías utilizadas

### Frontend:
- HTML5, CSS3, JavaScript, Bootstrap 5

### Backend:
- Node.js, Express.js, Helmet, CORS

### Base de datos:
- Supabase (PostgreSQL), Supabase Auth
